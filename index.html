Sobre o Projeto

O projeto MONITOR foi desenvolvido pelo grupo com o objetivo de apresentar uma solução tecnológica para monitoramento e acompanhamento de temperatura e umidade de salas de processadores, bancos de dados e outros ambientes que necessitam de controle ambiental voltados para a área de tecnologia da informação, utilizando sensores e microcontroladores para coletar dados em tempo real e fornecer informações precisas sobre as condições ambientais.

Durante o desenvolvimento do projeto, os integrantes trabalharam em conjunto para planejar, desenvolver e estruturar a solução, aplicando os conhecimentos adquiridos ao longo da materia em cumprimento dos objetivos propostos.

Esta página apresenta o projeto e os integrantes responsáveis pelo seu desenvolvimento.
